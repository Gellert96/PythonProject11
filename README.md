# Интернет-магазин на Django

Учебный проект интернет-магазина, разработанный на Django.

Проект будет постепенно дорабатываться в рамках курса. На текущем этапе реализованы главная страница, страница контактов и форма обратной связи.

## Функциональность

- Главная страница интернет-магазина.
- Страница контактов.
- Навигация между страницами.
- Bootstrap-стилизация.
- Форма обратной связи.
- Обработка POST-запросов.
- Сообщение об успешной отправке формы.

## Технологии

- Python
- Django
- HTML
- Bootstrap

## Установка

Клонируйте репозиторий и перейдите в директорию проекта.

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

Запустите Django-сервер:

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```

## Маршруты

- `/` — главная страница.
- `/contacts/` — страница контактов и форма обратной связи.

## Форма обратной связи

На странице контактов реализована форма с полями имени, электронной почты и сообщения.

После отправки данные обрабатываются Django-контроллером, а пользователю отображается сообщение об успешной отправке.
